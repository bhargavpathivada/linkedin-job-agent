Packaged DMG/EXE downloads will appear here for public beta. For now, run the companion from the project:

# In another terminal — Companion UI
cd companion
npm install
LETITAPPLY_API=http://127.0.0.1:8000 npm start

Requires Python 3.10+, pip install -e ".[saas]", and python -m playwright install chromium.
